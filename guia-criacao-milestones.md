# Guia Rápido: Como Criar os 8 Milestones no GitHub

Este guia fornece instruções passo a passo para criar os 8 milestones no seu repositório GitHub.

## Passo a Passo

### 1. Acessar a Área de Milestones
1. Vá para o seu repositório no GitHub
2. Clique na aba **"Issues"**
3. Clique em **"Milestones"** (ao lado de Labels)
4. Clique em **"New milestone"**

### 2. Dados para Cada Milestone

Copie e cole os dados abaixo para cada milestone:

## Dicas Importantes

### Para Definir as Datas
1. **Cronograma Pessoal**: Considere sua disponibilidade (1-3h por dia)
2. **Flexibilidade**: Pode ajustar as datas, mas mantenha a sequência
3. **Exemplo de Cronograma**:
   - Semana 1: 01/01 - 07/01
   - Semana 2: 08/01 - 14/01
   - Semana 3: 15/01 - 21/01
   - E assim por diante...

### Depois de Criar os Milestones
1. **Criar Issues**: Para cada tarefa diária, crie uma issue e associe ao milestone correspondente
2. **Acompanhar Progresso**: Use a visualização de milestones para ver o progresso
3. **Marcar como Completo**: Feche as issues conforme completa as tarefas

### Como Associar Issues aos Milestones
1. Ao criar uma nova issue, use o campo **"Milestone"** no painel direito
2. Selecione o milestone correspondente à semana da tarefa
3. Isso ajudará a visualizar o progresso de cada semana
