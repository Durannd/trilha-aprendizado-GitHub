# Trilha de Aprendizado GitHub - 8 Semanas

Este repositório contém um plano completo de aprendizado do GitHub Student Pack em 8 semanas, com tarefas diárias detalhadas e estrutura de milestones.

## 📋 Arquivos Principais

- **[plano_github_student_pack_8semanas_Version3.md](plano_github_student_pack_8semanas_Version3.md)** - Plano detalhado completo com todas as 8 semanas de atividades
- **[milestones.md](milestones.md)** - Documentação completa dos 8 milestones semanais
- **[guia-criacao-milestones.md](guia-criacao-milestones.md)** - Guia passo a passo para criar os milestones no GitHub

## 🎯 Milestones (8 Semanas)

### Semana 1: Fundamentos de Git e GitHub
Dominar commits, branches, PRs e fluxo GitHub

### Semana 2: README, documentação e portfólio  
Criar README profissional e página do portfólio

### Semana 3: Frontend básico + publicar site
Desenvolver site estático do portfólio e deploy

### Semana 4: App fullstack simples (CRUD)
Criar app fullstack (Node/Express + PostgreSQL + React)

### Semana 5: Deploy na cloud
Colocar app no ar (frontend + backend)

### Semana 6: CI/CD e testes automatizados
Implementar pipeline que roda testes e faz deploy automático

### Semana 7: Observabilidade, segurança e Dependabot
Rastreamento de erros, logs e atualização de dependências

### Semana 8: Contribuição OSS e preparação para entrevistas
Fazer 1 PR em OSS e preparar materiais de entrevista

## 🚀 Como Começar

1. **Leia o plano completo**: Comece pelo arquivo [plano_github_student_pack_8semanas_Version3.md](plano_github_student_pack_8semanas_Version3.md)
2. **Crie os milestones**: Use o [guia-criacao-milestones.md](guia-criacao-milestones.md) para criar os 8 milestones no seu repositório
3. **Crie issues diárias**: Para cada tarefa diária, crie uma issue e associe ao milestone correspondente
4. **Acompanhe o progresso**: Use a visualização de milestones do GitHub para monitorar seu avanço

## ⏰ Recomendações

- Reserve 1–3 horas por dia (ajuste conforme necessidade)
- Faça commits pequenos e frequentes
- Mantenha repositórios públicos para portfólio  
- Documente tudo: README, vídeo curto (1–2 min), screenshots
- Use Microsoft Learn sandboxes se não puder criar conta em provedores de cloud
