# Milestones - Trilha de Aprendizado GitHub (8 Semanas)

Este documento define os 8 milestones semanais para o plano de aprendizado GitHub Student Pack de 8 semanas. Cada milestone representa uma semana de atividades com objetivos específicos e entregáveis.

## Como criar os milestones no GitHub

1. Acesse seu repositório no GitHub
2. Vá para a aba "Issues"
3. Clique em "Milestones"
4. Clique em "New milestone"
5. Para cada milestone abaixo, preencha:
   - **Title**: Nome do milestone (ex: "Semana 1")
   - **Description**: Copie a descrição correspondente
   - **Due date**: Defina a data de conclusão (7 dias após o início)

## Milestone 1: Semana 1
**Título**: Semana 1  
**Descrição**: Fundamentos de Git e GitHub (Dias 1–7)  
**Duração**: 7 dias  
**Data de início sugerida**: [Definir conforme seu cronograma]  
**Data de conclusão**: [7 dias após o início]

### Objetivos
- Dominar commits, branches, PRs e fluxo GitHub
- Configurar ambiente de desenvolvimento
- Criar primeiro repositório de portfólio

### Entregáveis
- Repositório público com histórico de branches/PRs
- Git configurado corretamente
- 3 commits iniciais (README, .gitignore, descrição)
- PR criado e revisado
- Tag v0.1 e Release publicado
- 3 issues criadas (bug, melhoria, task)

### Tarefas Diárias
- **Dia 1**: Instalar Git; configurar user.name e user.email; criar repositório "portfolio-meu-nome"
- **Dia 2**: Criar branch feature/teste e fazer commits. Abrir PR via interface do GitHub
- **Dia 3**: Praticar merges: merge, squash e rebase. Testar cada um num repo de teste
- **Dia 4**: Simular conflito entre branches e resolver localmente
- **Dia 5**: Criar tag v0.1 e publicar Release com changelog
- **Dia 6**: Explorar Issues e Projects (kanban). Criar 3 issues (bug, melhoria, task)
- **Dia 7**: Criar PR com template e fazer revisão

### Dicas para Gerenciamento dos Milestones
1. **Planejamento**: Defina datas realistas considerando sua disponibilidade
2. **Flexibilidade**: Ajuste as datas conforme necessário, mas mantenha a sequência
3. **Documentação**: Registre seu progresso e aprendizados
4. **Issues**: Crie issues específicas para cada tarefa diária
5. **Reviews**: Faça revisões semanais do progresso
